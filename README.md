Overview

ESTATE is a front-end real estate web project focused on presenting property listings through a clean, modern, and user-friendly interface.

The platform allows visitors to explore properties, discover relevant information, browse property images, and navigate dedicated property detail pages.

Developed with a focus on visual consistency, usability, responsive layouts, and interactive user experiences.

Key Features

- Property Discovery — Browse available property listings.
- Property Details — Dedicated pages with extended descriptions, specifications, and property images.
- Search & Filtering — Explore properties using relevant search criteria.
- Image Gallery — View property photography in greater detail.
- Responsive Design — Optimized layouts for different screen sizes.
- Interactive Navigation — Clear navigation between the main sections and property pages.
- Contact Experience — Accessible contact information for property inquiries.

Getting Started

Prerequisites

- A modern web browser.
- A code editor such as Visual Studio Code.

Installation

Clone the repository:

git clone YOUR_REPOSITORY_URL

Navigate to the project directory:

cd ESTATE

Open "index.html" in your browser or use the VS Code Live Server extension.

Deployment

The project is deployed using Vercel.

Access the live application:

https://estate2-five.vercel.app/
